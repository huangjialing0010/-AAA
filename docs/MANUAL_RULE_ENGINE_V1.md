# 手工低频规则引擎 V1：实现契约

2026-09-29。落实已经批准的研究草案，不是新收益结论或正式实盘策略。代码在 `src/ashare_lab/selection/manual_rules.py`；测试在 `tests/test_manual_rules.py`。旧证据与开户记录不改写。

本步实现共用资格、左右侧入场标签和退出决策。资格使用最近3个已披露完整年度的归母净利润、经营现金流总额、ROE，禁止每股代理替代；3年均盈利、至少2年现金流正、现金流合计/归母利润合计>=0.8、ROE中位数>=10%、最近TTM归母利润正、20日成交额中位数>=2000万元。年度必须为信号日前最近3个已完成年度；年报未齐时保守等待，不混用更早年度。输入须有证据ID、核验日期等于信号日，所有财报可用日不得晚于信号日。

主板、非金融、满3年、非ST、标准审计及无已核实重大风险均须明确；未知不通过。门槛不证明无价值陷阱。日期与证据真实性仍须来源适配器独立核验，手工设置布尔值不是数据准入。

入场复用 current_watchlist 的已测价格/估值计算，但要求行情日等于信号日、资格先通过。L1/R1同时符合仍列待审，不猜归类。本次函数只产生 BUY_SIGNAL，不生成成交；周度/启动检查、月度频率、排序与组合约束由调度和组合层承担，尚未在此实现。

退出优先级：已确认硬风险或资格失效 > 公司行动调整后持仓总收益<=-12% > 持有126个交易日 > L1估值分位>=60% > R1连续两个完整周末收盘低于MA60。

L1的估值退出必须同时验证当前TTM归母利润未低于入场时值且持仓总收益为正，否则不得称为止盈；未满足不触发估值退出，明确给出待复核原因。已确认风险/止损/期限退出不因无关字段缺失被屏蔽。未知风险状态标记 REVIEW，不能当作安全持有；已触发的退出仍保留，等待交易条件。

不更改12%/60%/126日等假设，不实现自动调参。加仓、公司行动计算、完整组合调度及真实数据适配仍须接入，不能据此声称策略已全部定稿或运行。

## 单笔账户接入

`manual_execution.py` 将已产生的信号接入费用、整数股数适配、现有交易检查和账本。仅接受显式通过组合检查及公司行动核验的输入；调用者必须绑定证据，不能手工设置为真代替验证。只支持新开仓和整仓退出，不处理加仓。买入按开盘价加不利滑点向上取整到分，卖出反向处理；交易限制证据与执行证据须另行提供。滑点价格不在当日高低价内则拒绝，不捏造价格。

次日映射须来源于核验过的交易日历；订单只允许信号后的第一个交易日执行。重复成交ID一律拒绝重入账；未知标签/无信号、暂停、涨跌停、整手不足、未来现金等均保留原因。此适配器不计算组合排序与预算，不能单独开启账户自动交易。

风险与代价：资格保守且年报窗口严格可能排除本可研究的股票；止损可能无法成交，期限退出可能错过后续上涨。冻结研究假设是为了可复核，不代表阈值最优。
