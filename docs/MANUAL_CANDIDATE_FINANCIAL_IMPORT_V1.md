原始下载存入 `data/imports/manual_candidate_financial_<UTC时间戳>/`，保留服务器PDF原文件名，只追加；manifest记录代码、披露日、原始URL、哈希和已知限制。PDF内单位、年度列、归母利润和经营现金流总额须逐项核对；报告内审计结论不代表其后没有风险公告。

证券基本资料、行业与交易日历补充保存到 `data/imports/manual_reference_<UTC时间戳>/reference.json`，配套哈希manifest；当前行业只用于当下分散约束，不回填历史。行业证据同时保留提供商分类体系，不能把证监会分类冒充申万分类。

公告清单与原文保存在 `data/imports/manual_announcements_<代码>_<UTC时间戳>/`。逐页核对总条数、去重和证券代码；全部原文保存为原始文件名。清单检查不等于风险审阅；需单独记录审阅范围、结论与时刻。未封存的抓取不准入。

风险：报告比較数字可能重述，仅允许前向研究；公告日期与财务项目解析错误会影响资格，须保留原文页码并独立复算。公开资料不能证明不存在任何风险，必须明确审阅范围与未知项。
