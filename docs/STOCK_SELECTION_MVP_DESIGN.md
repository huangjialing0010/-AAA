# 历史沪深300价格量选股 MVP 设计（冻结版 V1）

状态：`APPROVED_AND_FROZEN`

批准日期：2026-09-04

## 目标与边界

本实验只回答一个问题：在不使用财务数据、新闻、模型预测和实盘接口的前提下，历史沪深300成分内的“12-1 动量 + 低波动”月度选股组合，能否在严格计入交易约束和成本后，在未参与设计的样本外区间优于510300持有基准。

本实验不承诺盈利，不连接券商，不发送真实订单。GitHub项目只用于借鉴数据适配、分层、回测和审计结构，不继承外部项目的收益结论。

## 数据准入

- 历史股票池：`baostock_hs300_history_20260903T062132Z`。
- 仅使用 `query_date <= signal_date` 的最后一组成分，不把未来查询结果按 `updateDate` 倒灌。
- 正式研究从2013-01-01开始；历史成分快照唯一缺口在2007-07-23，早于本实验及其价格回看区间。
- 个股日线必须覆盖历史成分出现过的940只股票，同一BaoStock批次同时包含 `adjustflag=3` 不复权和 `adjustflag=2` 前复权。
- 只有原始快照 `status=SEALED` 且独立质量报告 `status=PASS` 时才能标准化和回测。
- 前复权收盘价只用于收益和因子；不复权开盘价、成交量、成交额、交易状态和ST状态用于成交、过滤和账本。
- 510300基准使用已封存的含现金分红总收益数据 `data/canonical/mvp_510300_v2`。
- 财务因子保持关闭，避免使用未经公告首次可用日验证的数据。

## 固定策略

### 信号日与成交日

- 每个自然月最后一个交易日收盘后计算信号。
- 所有因子只使用该日及以前的数据。
- 下一交易日开盘执行，信号日与成交日严格分离。
- 月内不因为排名变化交易；被拒订单不在月内追单，留到下一次月度调仓重新判断。

### 股票资格

股票在信号日同时满足以下条件才可排名：

1. 属于截至信号日最后一次可观测的沪深300成分集合；
2. 当日 `tradestatus=1`、`isST=0`，且价格和成交字段完整；
3. 至少有252个有效前复权交易日，排除上市早期和历史不足股票；
4. 最近20个有效交易日成交额中位数不低于2000万元；
5. 计算窗口内收盘价均为正，日期严格递增且无重复。

### 因子和排序

- 12-1动量：`close_qfq[t-21] / close_qfq[t-252] - 1`。
- 63日波动率：最近63个日收益率的样本标准差乘以 `sqrt(252)`。
- 在当月合格股票中分别计算百分位排名：动量越高越好，波动率越低越好。
- 综合分数：`0.5 * momentum_percentile + 0.5 * low_volatility_percentile`。
- 分数相同按股票代码升序打破并列，不允许人工选择。
- 主策略持有前30只，等权，目标总仓位95%；其余保留现金支付成本和处理拒单。
- 稳健性旁路只运行前20只和前40只两个预先登记的邻域，不据此修改主策略。

## 成交与账本

- 先卖后买；卖出所得在同一成交日可用于后续买入。
- 普通股票买入数量按100股整数倍；科创板首次买入至少200股，超过200股后允许按1股递增；碎股只允许一次性卖出。
- 停牌、成交量为0或关键字段缺失时拒单。
- 日线无法观察排队顺序，因此采用保守的一字板规则：买入日 `open=high=low` 且涨幅大于4.5%时拒绝买入；卖出日 `open=high=low` 且跌幅小于-4.5%时拒绝卖出。
- 成交价在不复权开盘价基础上加入单边5bp滑点。
- 佣金按成交额0.03%、单笔最低5元、双向收取；该值视为含经手费和监管费的研究场景，不代表具体券商报价。
- 股票卖出印花税：2023-08-28以前按0.10%，当日及以后按0.05%；买入不收。
- T+1：当日买入的股票当日不可卖出。月频策略通常不触发，但账本必须保留约束。
- 每日恒等式必须成立：`现金 + 持仓市值 + 应收款 = 权益`；订单、成交、拒单、费用和持仓逐笔可追溯。

## 时间分段

- 预热期：2010-01-01至2012-12-31，只用于形成因子历史。
- 开发观察段：2013-01-01至2018-12-31，不用于修改本冻结参数。
- 中间验证段：2019-01-01至2022-12-31。
- 最终样本外段：2023-01-03至数据封存截止日；这是唯一晋级判定区间。

## 预先冻结的研究闸门

主策略只有同时满足以下条件才可进入持续虚拟盘：

1. 最终样本外扣费总收益为正；
2. 最终样本外总收益高于同期510300含分红、含成本买入持有；
3. 最终样本外最大回撤绝对值小于510300基准；
4. 最终样本外Calmar不低于510300基准；
5. 2023年起完整自然年中，至少三分之二年度取得正超额收益；不足完整年度不计入比例；
6. 佣金、印花税和滑点整体放大到2倍后，最终样本外总收益仍为正；
7. 前20只和前40只两个邻域在最终样本外均保持扣费正收益；
8. 独立验证器复算订单、成交、成本、持仓、现金和权益无错误。

任一条件失败即记为 `RESEARCH_GATE=FAIL`。失败后不得在同一最终样本外区间内反复修改参数再声称是样本外结果；新策略必须建立新版本并更换或滚动冻结验证方案。

## 已知风险和代价

- 预计需要5,640次BaoStock顺序查询，试验折算约9.9小时、约0.94GB；断线会延长时间，但允许按哈希断点续跑。
- 历史成分为周频免费数据，可能遗漏周中临时调整，且尚未逐条对照中证指数官方公告。
- BaoStock历史前复权序列可能随后续公司行动回溯变化；本次哈希只能证明本批数据内容。
- 日线无法还原涨跌停排队和盘中成交顺序，一字板拒单是假设，不等同真实成交。
- 不包含退市整理、配股、换股吸收合并等所有特殊公司行动；发现相关账本异常时必须阻断，不能自动填补。
- 940只股票只是历史沪深300范围，不代表全A股；即使通过，也只能证明该研究设定下有继续观察价值。
