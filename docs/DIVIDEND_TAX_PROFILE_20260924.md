# 虚拟账户分红税务口径 V1

## 固定口径

虚拟账户暂按“自然人 A 股”建模：分红发放日按公告的实际发放金额计入现金；持股一年以内不在发放日直接扣税，出售时按买入批次计算递延税负；持股超过一年税负按本口径为零。买入批次采用 FIFO 供税负归属，实际账户若存在不同身份或特殊股份，必须另建配置。

政策依据为财税〔2015〕101号：持股一个月以内（含一个月）按20%计征，持股一个月至一年（含一年）按50%计入应纳税所得额后按20%计征，超过一年暂免；发放时一年以内暂不扣缴，转让时再由托管机构扣收。政策页面注明自2015年9月8日起施行，因此更早登记日不自动套用本版本。

## 工程边界

`src/ashare_lab/selection/dividend_tax.py` 只计算模拟递延负债，不替代个人税务判断，也没有改变现金支付。没有买入批次、账户身份或政策覆盖时返回阻断；不能把“暂不扣缴”当作最终免税。

下一步把这个配置接入标准事件与真实历史成交重放，逐笔输出税前现金、递延税负和剩余持仓。完成前保持虚拟账户晋级阻断。
