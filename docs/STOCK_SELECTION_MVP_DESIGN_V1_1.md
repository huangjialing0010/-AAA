# 历史沪深300价格量选股 MVP 设计（冻结版 V1.1）

状态：`APPROVED_AND_FROZEN`

基线文件：`docs/STOCK_SELECTION_MVP_DESIGN.md`

变更决策：`docs/DECISION_20260904_SELECTION_ACCOUNTING_SCOPE.md`

## 本版本覆盖V1的内容

V1中的股票池、数据准入、信号日期、因子、排名、持股数、目标仓位、成本、样本分段和研究闸门全部保持不变。

本轮会计范围改为 `RESEARCH_PORTFOLIO`：

- 每只持仓以目标权重和前复权总收益序列计算每日持有收益；
- 调仓日用不复权开盘价和成交状态判断停牌、一字涨跌停与最小下单单位可行性；
- 交易费用按名义成交金额扣减；买卖名义金额来源于调仓前权益和目标权重；
- 未成交卖出继续保留原权重暴露，未成交买入保留为现金权重；
- 输出组合权益是研究净值账户，不是券商现金和真实股数账户；
- 不生成分红应收、送转后股数或持仓成本等需要完整公司行动的数据。

## 权重收益和成交时点

1. 信号日在收盘后形成目标股票集合。
2. 下一交易日以不复权行情判定是否可交易，以前复权开盘价计算从成交点开始的收益衔接。
3. 卖出成交前，原持仓承担前一收盘到当日模拟卖出价的前复权收益；买入成交后，新持仓承担当日模拟买入价到收盘的前复权收益。
4. 非调仓日按前复权收盘价之比计算持有收益。
5. 单边滑点5bp直接作用于名义成交额；佣金和印花税另行扣减，避免把不复权股数与前复权价格混为同一计量单位。

## V1研究闸门的解释修订

V1第8项仍要求独立验证订单、名义成交、费用、持仓权重和每日组合权益；其中“现金和真实股数账本”由本版本明确排除。

即使所有研究闸门通过，结果也只能标记 `ELIGIBLE_FOR_CORPORATE_ACTION_LEDGER_BUILD`，不能标记为 `ELIGIBLE_FOR_PAPER_TRADING`。
