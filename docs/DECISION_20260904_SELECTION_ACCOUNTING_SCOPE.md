# 选股 MVP 公司行动与账本口径决策（已批准）

状态：`APPROVED_OPTION_A`

日期：2026-09-04

批准结果：用户选择方案A。本文件同时作为选股MVP设计V1.1的口径变更记录；未被本文件覆盖的V1规则继续有效。

## 新发现的事实

1. 已批准的选股设计要求用前复权价格计算因子、用不复权价格成交，并生成真实股数、现金和持仓账本。
2. 个股长期持有期间会发生现金分红、送股、转增、配股、换股等公司行动。
3. 前复权日线可以近似表达持有期总收益，但不能单独说明真实账户何时收到现金、持股数量如何变化。
4. 当前940只全量日线任务不包含公司行动明细。若直接把不复权股数乘以前复权价格，会混合两种单位，资产恒等式虽可能形式上成立，经济含义却是错误的。
5. BaoStock存在分红和复权因子接口，但要覆盖940只、2010年至今并验证现金分红和股本变化，需要新增数据快照、校验器和公司行动账本规则；免费接口仍可能缺少配股、换股等特殊事件的完整处理信息。

## 方案A：研究收益 MVP（推荐）

- 本轮只验证选股策略是否存在研究价值。
- 因子和每日持有收益全部使用同批次前复权序列。
- 不复权行情只用于停牌、一字涨跌停、成交额、ST状态和按实际价格估算交易成本、手数可行性。
- 输出目标权重、模拟订单、名义成交额、费用、组合收益和持仓权重。
- 明确标记为 `RESEARCH_PORTFOLIO`，不声称是真实股数/现金账户，不进入持续虚拟盘。
- 如果研究闸门通过，再补公司行动数据和真实份额账本，完成第二次技术准入后才进入虚拟盘。

收益：最快得到策略是否值得继续的答案，不把大量时间花在可能被淘汰的策略上。

风险与代价：不能直接作为实盘指令；按日线和名义成交额估算的成本仍是研究近似；真实账户路径要在后续重建。

## 方案B：先补齐公司行动，再做真实账本

- 为940只股票补抓分红和复权因子，并对现金分红、送转、配股、换股建立事件模型。
- 抽样与交易所或上市公司公告交叉核对，未覆盖的特殊事件对应区间阻断。
- 完成真实股数、现金、应收款和持仓成本账本后再运行策略。

收益：结果更接近未来虚拟盘和实盘账户语义，减少后续重建。

风险与代价：预计增加数千至上万次查询、较多人工核验和至少一个开发阶段；免费数据仍可能无法完整证明所有特殊公司行动，可能投入较多后仍被阻断。

## 建议

选择方案A。先让策略接受样本外和成本压力检验；只有策略通过，才为它支付公司行动全量治理成本。无论选择哪一项，当前940只双口径日线抓取都继续，因为两种方案都需要该数据。

实施约束：

- 所有运行清单、指标和报告必须标记 `accounting_scope=RESEARCH_PORTFOLIO`；
- 输出目标权重、名义订单、名义成交额、成本扣减、每日组合权益和持仓权重，不输出伪造的真实股数、现金余额或分红应收账款；
- 100股/科创板200股约束只用于判断目标名义交易是否至少具备最小下单可行性，不用于构造长期真实股数；
- 研究组合通过全部闸门也只能进入“公司行动与真实账本建设候选”，不得直接晋级持续虚拟盘或实盘；
- 若研究闸门失败，本策略直接淘汰，不为其补建公司行动账本。
