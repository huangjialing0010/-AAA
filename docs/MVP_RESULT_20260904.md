# 510300最小MVP实验结论

状态：`COMPLETED_AND_AUDITED`。

## 事实

- 输入：腾讯不复权日K 3,468日，2012-05-28至2026-09-01；现金分红14次。
- 数据核对：交易日历3,468日完全一致；新浪重叠1,021日价格零差异；BaoStock重叠161日价格零差异。
- 主策略：总回报指数高于200日简单移动平均线时，下一交易日开盘持有；否则持有现金。
- 成本情景：佣金0.03%、最低5元、单边滑点5bp、ETF印花税0、100份整数。
- 样本外区间：2023-01-03至2026-09-01，共888个交易日。
- 200日策略样本外含成本总收益12.9699%，年化收益3.5214%，最大回撤-16.3748%，Calmar 0.2150。
- 买入持有样本外含成本总收益24.5430%，年化收益6.4266%，最大回撤-19.8651%，Calmar 0.3235。
- 180日、200日、220日样本外收益均为正。
- 独立审计验证3,468行账本、3,269条信号、84个订单、84笔成交、14次分红事件，未发现T+1、费用、整数份额、资产恒等式或哈希错误。

## 判断

系统最小闭环通过，但200日均线策略未通过研究闸门。它降低了最大回撤，却明显跑输买入持有，且Calmar低于基准。不能为了让策略通过而改用180日或220日参数，也不能把“收益为正”解释成“实现长期盈利”。

## 方案

保留数据层、撮合层、账本和审计工具，淘汰当前200日均线策略假设。下一步如继续，应先批准一个新的、预先冻结的策略实验设计，再运行样本外测试。实盘接口继续不进入范围。

## 风险和代价

- 单只ETF不验证选股能力，无法回答个股组合是否存在Alpha。
- 公开网页数据虽经交叉验证，仍不具备正式实盘数据服务等级。
- 佣金和滑点是研究情景，不代表真实账户；不同费率会改变绝对收益，但本次相对买入持有差距较大。
- 继续研究需要新的独立假设和新的样本外纪律；连续试很多策略会形成策略层面的数据挖掘偏差。
