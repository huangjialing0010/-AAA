# 组合烟测基准支配判定

日期：2026-09-09  
状态：IMPLEMENTATION_APPROVED_BY_CONTINUATION

## 规则

组合烟测必须与同区间、含现金分红的 510300 总回报指数比较。若候选组合同时满足以下三项，则记为 `REJECTED_BENCHMARK_DOMINATED`，不得晋级虚拟盘：

1. 年化收益不高于基准；
2. 最大回撤绝对值不低于基准；
3. 零利率夏普不高于基准。

该规则只做否决，不因单次跑赢自动批准。通过支配检查的策略仍需滚动训练、完整历史成分范围、成本压力和前向验证。

## 数据边界

- 基准使用已封存 `data/canonical/mvp_510300_v2/daily.csv` 的 `total_return_index`，不是只看价格涨跌。
- 基准与组合使用相同起止日期、相同交易日数量，并使用区间前一日作为收益基线。
- 这是研究评价，不是收益承诺。

## 风险与代价

全面支配规则较保守，可能拒绝某些有其他用途的低相关策略；当前系统尚未计算组合与基准相关性和信息比率，因此先不以“分散价值”为由豁免。基准数据若出现分红遗漏，比较会失真，必须继续保留封存和质量报告引用。
