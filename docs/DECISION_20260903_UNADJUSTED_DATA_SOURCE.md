# 决策记录：不复权历史数据来源调整

## 结论

停止使用 BaoStock 单次超长区间查询来重建完整不复权历史。改为一次性复制旧项目每只股票最新的无 `qfq` 文件，作为独立候选快照；BaoStock 仅用于抽样交叉验证和后续短区间补数。

## 事实证据

- 旧项目共有2498个无 `qfq` 历史文件，按六位代码取文件名日期最新值后为766只股票。
- 766个最新文件名日期全部为20260807，字段结构完全一致，总体积215,618,180字节。
- 已下载的145只 BaoStock 不复权文件中，144只具有2026-07-01后的共同交易日。
- 144只股票、合计3,889个共同交易日，收盘价和成交量逐日完全一致。
- `600196` 的 BaoStock 文件恰好只有4000行并停在2015-02-16；客户端分页大小为2000行，日志显示后续翻页期间发生连接失败。该文件证明“查询返回成功码”不能保证完整历史。

## 判断

旧无 `qfq` 文件的不复权语义得到强交叉证据支持。继续通过 BaoStock 长区间分页重下，耗时更长且存在静默截断风险，不增加数据可信度。

这项判断不等于766个文件已经获准进入正式回测。它们先进入独立原始快照，仍需逐文件日期、唯一性、OHLC、哈希和覆盖范围验证。

## 执行规则

1. 每个六位股票代码只复制文件名日期最新的无 `qfq` CSV。
2. 复制而非移动，不修改旧项目文件。
3. 源文件和目标文件逐一计算 SHA256，任何不一致立即阻断。
4. 快照类别明确写为 `unadjusted_daily_candidate`。
5. 现有 BaoStock 145文件目录写入 `REJECTED_INCOMPLETE` 清单并保留，不删除、不续跑、不进入标准层。
6. 未来增量补数必须采用短日期窗口，且先与既有数据重叠核对。

## 风险和代价

- 新快照约205.63MB，会增加磁盘占用。
- 766只股票仍不等于完整A股历史股票池；正式选股范围必须由历史成分数据决定。
- 旧文件缺少 BaoStock 的 `tradestatus`、`isST` 和 `preclose` 字段；停牌可用交易日历与缺失行情识别，历史ST状态仍需另行补充。
- 数据截止2026-08-07，之后日期仍需增量更新。
