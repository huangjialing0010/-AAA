# 300114→302132证券代码沿革处理决策

状态：`APPROVED`（2026-09-04）。

## 发现的事实

1. 中航成飞股份有限公司公告显示，证券代码于2025年2月17日由`300114`变更为`302132`；上市法人主体延续，股份数量和投资者持股期限连续。
2. 公告原文：<https://disc.static.szse.cn/disc/disk03/finalpage/2025-02-15/cedb693a-f5ee-4463-9682-ea33d406b569.PDF>。
3. BaoStock对`302132`请求`adjustflag=2`时，2025年2月14日及以前的行实际返回`adjustflag=3`；2025年2月17日起返回`adjustflag=2`。
4. 对旧代码`300114`请求2025年2月14日及以前的`adjustflag=2`，返回标记正确；与`302132`不复权响应在重叠日期的行情字段可核对。
5. `302132`从2025年6月16日起出现在本项目沪深300历史成分快照中，但选股因子需要成员生效日前的历史回看数据，因此不能简单删除变更日前数据。

## 批准方案

- 有效研究代码保持`302132`。
- `daily_qfq`在2025年2月14日及以前使用查询代码`300114`，2025年2月17日起使用`302132`，禁止一个查询任务跨越代码变更边界。
- `daily_unadjusted`保留既有`302132`查询的原始响应，不覆盖、不重写。
- 原始CSV保留BaoStock实际返回代码；任务元数据分别记录`stock_code`、`query_stock_code`和`response_stock_code`。
- 只有在独立验收确认双口径日期一致、成交字段一致、变更日前后昨收连续及复权比例连续后，标准层才把旧代码响应映射为`302132`。
- 现有未封存快照从任务状态版本1迁移至版本2；已下载CSV及其哈希不变。

## 风险和代价

- `302132`的前复权第三时间窗需拆成两个文件，全量预期数据文件数由5640变为5641。
- 同一证券存在两个历史查询代码，抓取器、独立验收器和标准化器都必须理解代码沿革，复杂度上升。
- 若切换边界价格、昨收或复权比例不连续，快照必须验收失败，不能通过手工填值或放宽容差进入回测。
- 本规则只适用于已核实的`300114→302132`沿革，不推广为任意代码自动拼接。

## 不采用的方案

- 不接受BaoStock返回的错误复权标记：会把不复权价格误当成前复权价格。
- 不删除`302132`：会改变已批准的历史成分样本，并造成成员生效日前回看期不足。
- 不把原始CSV中的`300114`直接改写为`302132`：会破坏原始响应保真和审计链。
