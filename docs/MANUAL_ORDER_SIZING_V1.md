# 低频虚拟盘订单金额适配 V1

2026-09-29；依据报告复盘 V2 的资金适配要求实施，不冻结策略阈值。

范围：仅计算新开仓可承受的整数股数，不创建订单或成交，不支持加仓。账户资金、剩余单股预算、剩余总仓位预算均由调用者显式提供；取三者最小值作为含买入费用的支出上限。不能为凑整手提高任何上限。

输入价格必须是不复权且已包含不利滑点、按有效报价单位处理后的预计执行价；费用使用既有 FeeRuleProfile。数量规则由已核定交易规则传入，不按股票代码猜测。输出区分“数量可行，不代表可成交”和“预算不足一手”。缺失、非有限值或异常参数抛错，不默认为零。

撮合前仍须重新校验价格、预算、持仓、交易日、板块、信号、公司行动、可交易状态及涨跌停；不能把数量结果直接交给账本冒充成交。价格变化须重新计算。本模块不进行并发资金预留。

风险与代价：保守地将费用计入仓位预算会略微降低实际股票仓位；高价股票可能被拒绝。这比增资或放宽集中度更符合既定研究约束。单元测试使用合成价格和研究费率，不是行情或投资建议。
