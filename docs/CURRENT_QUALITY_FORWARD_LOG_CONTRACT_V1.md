# 当前质量策略前向记录契约 V1

日期：2026-09-28

## 目的与状态

本契约只负责从已准入观察名单开始，建立可审计的前向信号、订单、成交、拒绝、持仓和对账记录。当前状态为 `SIGNAL_LOG_READY_EXECUTION_NOT_CONFIGURED`；退出规则和研究本金未冻结前，不生成虚拟订单。

## 不可变边界

- 起始准入文件必须为 `ADMITTED_FOR_FORWARD_OBSERVATION_ONLY`，观察名单文件必须为 `FORWARD_WATCH_ONLY`。
- 2026-09-28为冻结日，2026-09-24及以前的触发全部记为 `BASELINE_PRE_FREEZE`，不得回填订单或成交。
- 每次刷新创建新的不可覆盖报告目录，引用上一批次清单及 SHA256；不得改写历史CSV。
- 只在冻结后的完整周最后交易日计算新信号；信号日与最早计划成交日分离，最早为下一交易日。
- 资金或退出规则未配置时，新信号可以记录，但订单必须拒绝为 `CAPITAL_AND_EXIT_RULES_UNSET`。
- 不接券商、不发送真实订单。

## 文件

- `signals.csv`：基线与未来信号事件；记录规则版本、数据截止日、机制、是否可行动及原因。
- `orders.csv`：计划订单；当前只含表头。
- `trades.csv`：实际虚拟成交及费用；当前只含表头。
- `rejections.csv`：拒绝原因；当前只含表头。
- `positions.csv`：真实股数语义的虚拟持仓；当前只含表头。
- `daily_reconciliation.csv`：现金、持仓市值、权益和对账状态；初始化行不填金额，状态为 `NOT_APPLICABLE_CAPITAL_UNSET`。
- `manifest.json`：文件哈希、行数、准入谱系和计数。

## 尚待冻结的执行参数

1. 研究本金与100股整数手数；
2. L1和R1各自的止损、止盈、趋势退出和最长持有期；

这些参数会影响盈亏和是否成交，不能在看到未来结果后再选择。
