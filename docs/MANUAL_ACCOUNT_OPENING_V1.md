# 模拟账户开户约定

2026-09-29，用户要求启动。沿用10万元研究展示资金，不代表用户实盘资金；5万/20万对照尚未开户。

本步骤只建立全现金账户及审计起点，状态必须为 OPEN_BUYING_BLOCKED。策略草案未冻结、最新行情未核验、完整成交链未接入前，禁止生成买单。不把开户称为已开始策略交易；开户净资产是100000元，策略收益为null而非0%。
