# 左右侧价格机制诊断决策

日期：2026-09-28

状态：`PRICE_ONLY_NOT_PROMOTED`

## 决策

不把当前L1“252日高点回撤20%”或R1“突破120日高点且60日趋势改善”单独升级为选股策略、四股组合或虚拟交易规则。它们可以保留为完整策略中的候选入场标签，但必须先经过公司质量/估值筛选，并另行验证退出规则；现有结果不能支持直接拿价格形态选少量股票。

这不是对完整“质量筛选 + 估值 + L1/R1 + 风险退出”策略的最终否决，因为本轮刻意没有使用财务、估值、退出、仓位和成本。它否决的是更窄的假设：价格形态本身足以提供可用于少量手工持仓的稳定优势。

## 证据

正式封存运行：`reports/price_mechanism_diagnostic_20260928T035756Z/`。

- 940个标准行情文件全部重新核对哈希；历史成分实际覆盖800只证券、853个周频观察日。
- 去重后L1信号6,919个、R1信号3,285个，共10,204个信号；生成30,612条21/63/126日观察。
- L1在21/63/126日的中位超额分别为-0.91%、-2.33%、-4.21%，超额为正比例分别为44.61%、42.01%、40.48%。
- R1在21/63/126日的中位超额分别为-1.45%、-2.97%、-3.12%，超额为正比例分别为43.06%、42.36%、44.27%。
- 两种机制在三个期限、四个固定阶段的中位超额全部为负。R1的126日平均超额为正0.97%，且四个阶段平均超额均为正，但总体中位超额和命中率仍为负面，说明均值主要由少数大赢家拉动；对只持有少量股票的手工账户，这种分布不能当作稳定优势。
- 独立校验复算收益、总体均值/中位数、观察覆盖和所有输出/输入/实现代码哈希，状态为 `PASS`；报告为 `reports/price_mechanism_diagnostic_20260928T035756Z_validation.json`。

## 对原研究设计的影响

`docs/MANUAL_LOW_FREQUENCY_STRATEGY_V1.md` 继续保留为研究假设来源，但状态不得解释为已定策略。L1/R1阈值不再被当成默认有效参数；不得基于本次历史结果微调为18%、22%、100日、150日后重新宣称独立样本外。

最快且更贴合用户目的的下一阶段，不是继续扩大纯价格回测，而是设计一个小范围“当前质量候选池 + 左右侧观察标签”的真实前向虚拟试验：先用当前时点可审计的财务质量筛到少量候选，再从新到达行情开始记录L1/R1、人工可执行计划和完整未成交原因。它可以尽快验证完整工作流，但需要等待未来数据，短期不能给出长期盈利证明。

## 风险与代价

- 本轮是历史沪深300周频成分事件研究，不是全A；成员历史和日线可成交性仍有已知限制。
- 没有验证止损、趋势退出能否改善R1的偏斜收益，也没有验证质量/估值过滤是否能把少数赢家筛出来；因此不能说左右侧思想无效，只能说当前纯价格实现证据不足。
- 转向真实前向试验会减少数据工程和历史穿越风险，但学习速度慢，几个月可能没有完整卖出回合；少量持仓也会带来较高个股偶然性。
