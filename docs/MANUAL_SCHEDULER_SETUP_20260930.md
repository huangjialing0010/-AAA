# 本地与 GitHub 收盘任务

## GitHub Actions

`.github/workflows/manual-close-cycle.yml` 使用工作日17:00（北京时间）对应的09:00 UTC，并以交易日历和证据时间为准。首次启用前需检查仓库权限、公开报告范围和 Actions 是否允许写入；失败时不得把旧报告当作新结果。网络数据源失败会使该次运行失败或等待，不会制造行情。

## 本地 Windows 任务

可执行入口：`tools/run_manual_close_cycle.ps1`。建议在任务计划程序中设置工作日17:00触发，工作目录为项目根目录，使用项目指定 Python。任务注册属于系统配置，本文件不自动注册；注册前应确认电脑开机、账户权限和日志位置。

两端调用同一 Python 编排器，依靠订单终态、来源哈希和报告幂等键避免重复记账。若两端同时运行，第二次应读取已存在终态，而不是新增成交。

## 当前限制

这是收盘编排入口，不是实盘接口。正式推荐仍必须绑定模拟订单；缺盘前资格、收盘行情、公司行动或可成交证据时，只记录等待/拒绝。GitHub Actions 的计划触发可能延迟，不能把触发时刻当作行情时刻。
