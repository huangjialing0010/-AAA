# 510300 MVP主行情源第二次变更决策

状态：`APPROVED`（2026-09-03）。

## 结论

建议停止“Yahoo主源加逐日修补”的实现，改用“腾讯不复权行情主源 + 新浪近期交叉验证和分红 + BaoStock近期交叉验证”。这不是为了追求更多数据，而是因为Yahoo已经表现出系统性的数据质量问题。

## 新证据

1. Yahoo的2019-01-07开盘价为3.001，低于当日最低价3.091，违反OHLC基本关系；全段扫描确认这是唯一一条内部自相矛盾记录。
2. 腾讯前复权序列在该日为开2.497、收2.495、高2.506、低2.479。以Yahoo有效收盘价推导同日现金调整差0.612后，开盘价应为3.109，且高、低、收三项也都严格对应。
3. 腾讯不复权接口分两段返回2012-05-28至2026-09-01共3,468个交易日，与项目现有交易日历逐日完全一致。
4. Yahoo只有3,466个日期，缺失交易日2019-04-29和2019-04-30；项目交易日历和沪深300指数数据均确认这两日开市。
5. 腾讯与新浪最近1,021个共同日期的OHLC全部一致，成交量换算为份后差异均不超过100份。
6. 腾讯与BaoStock 2026年161个共同日期的OHLC全部一致，成交量换算为份后差异均不超过100份。
7. 腾讯成交量以“手”为单位并保留到小数，标准化时乘100转换为份；该转换必须写入清单和测试。

## 建议的数据结构

- 主成交行情：腾讯不复权日K，3,468日；
- 分红与总回报：新浪14次现金分红，自行构建总回报指数；
- 交叉验证一：新浪最近1,021个共同完整交易日；
- 交叉验证二：BaoStock 2026年161个交易日；
- Yahoo：降级为被拒绝候选源，仅保留此前快照和质量报告，不进入新标准数据。

## 好处

- 不需要维护5个Yahoo例外日或根据复权价反推原始价格；
- 交易日与现有独立交易日历完全一致；
- 两组交叉验证均无价格差异，数据链更简单；
- 仍保留不复权成交、分红总回报信号和逐文件哈希。

## 风险和代价

- 腾讯仍是公开网页接口，不是付费授权数据服务，未来可能改版或停用；
- 成交量从手换算为份，跨源允许最多100份尾差，不能宣称逐份完全一致；
- 需要重新生成并验收一次快照；此前已封存的Yahoo快照保留为失败证据，不修改、不删除；
- 该方案仍只能支持MVP研究，不能直接作为未来实盘的数据供应方案。

## 批准后的验收闸门

1. 腾讯主行情必须恰好覆盖交易日历的3,468日，OHLC关系全部有效；
2. 与新浪1,021日、BaoStock 161日重叠期价格零差异；
3. 两组成交量换算差异均不得超过100份；
4. 14次分红的登记、除息、发放日期都必须存在于主行情交易日；
5. 独立验收通过并封存后，才重新生成MVP标准数据。
