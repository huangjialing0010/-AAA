# 复牌冷却期候选规则设计

状态：CANDIDATE_IMPLEMENTED_NOT_PROMOTED。已实现资格层参数并通过合成边界测试；只用于新版本敏感性实验，不修改 V1 冻结策略。

## 目的

停牌期间的平价记录可能压低历史波动率。仅按窗口内停牌天数放宽，会把停牌股带入低波动排名；本候选规则改为：股票复牌后经过一段可登记的交易日，才允许进入因子排名。

## 严格时间语义

对信号日 `t` 的股票 `i`：

1. `t` 当日必须 `tradestatus=1`，且有有效前复权开盘价和收盘价；
2. 从 `t` 向前按交易日历回看，找到最近一次 `tradestatus=0` 的连续停牌段；
3. 若该停牌段结束后的可交易日数量小于冷却参数 `C`，则该股票不进入排名；
4. 找不到有效前复权价格、连续缺失超过60个交易日或不满足窗口长度，仍然拒绝；不插值、不补零、不压缩日历；
5. 冷却期只改变候选资格，不改变成交价、T+1、成本、涨跌停和最小交易单位规则。

## 预登记对照

固定比较 `C=0`（短停≤5日基线）、`C=5`、`C=10`、`C=20`。四个版本使用完全相同的数据快照、历史成分、信号日、评价区间和成本。不得因收益结果临时选择冷却天数。

## 验收指标

- 首个信号日及每个信号日的合格数量；少于40只则该口径记为不可运行，不降低持股门槛；
- 前30名中曾停牌股票数、窗口停牌天数、最长连续停牌段；
- 复牌后冷却命中数及行业/规模集中度变化；
- 独立因子审计、订单/成交/拒单/现金/持仓/每日账本审计；
- 策略收益、最大回撤、换手、成本敏感性仅作为描述性结果，不作为单独选规依据；
- 完成共同区间的前向虚拟盘后，才讨论是否进入下一版本。

## 风险与代价

冷却期可能错过真实的复牌反转，也可能把有充分流动性的复牌股票排除，造成行业和规模偏斜。`C` 越大，候选数越少，组合可能无法运行；四路实验增加计算和审计成本。该规则不能修复缺失前复权数据，`000527` 的连续价格缺失仍必须触发数据闸门。

## 实施前置条件

已先用合成序列验证停牌段长度、复牌日和冷却边界（资格测试 12/12 通过），并完成代表日资格审计。冷却5日全历史运行在账本阶段因 `000527` 连续超过60个交易日没有有效前复权价格而停止；该数据闸门不因冷却规则放宽。Qlib 适配实验必须沿用同一数据准入和冷却口径，不能用模型绕过该闸门。
