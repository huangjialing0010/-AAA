# Qlib 组合烟测历史成分准入修正

日期：2026-09-09  
状态：IMPLEMENTATION_APPROVED_BY_CONTINUATION

## 根因

`run_qlib_alpha_portfolio_smoke.py` 从历史出现过的证券代码中固定取前 100 只，按模型分数直接选前 20，只检查当日是否有特征样本，没有按信号日可见的沪深 300 历史成分过滤。`000540` 的标准层成分观察止于 2018-12-10，却能在 2023 年被烟测选入；后续退市阻断因此首先暴露的是股票池时间语义错误，而不是需要先设计退市结算价。

## 修正

1. 模型研究覆盖仍保持按代码排序的固定 100 只，不改训练集，保证与既有 IC 结果可比。
2. 组合信号阶段对每个信号日调用 `MembershipHistory.as_of(signal_date)`，只允许当日可见成分进入排名。
3. 报告记录每期合格候选数的最小值、最大值、目标持仓数和成分来源；不足 20 只时只持有实际数量，不用区间外股票补足。
4. 继续保留退市事件闸门；若修正后仍合法持有退市证券，再处理真实的公司行动或退市板块估值。

## 风险与代价

- 固定前 100 只只是工程烟测，不代表完整沪深 300；历史成分过滤后每期可选数量会下降，收益结果不能与未过滤版本直接比较。
- 周频成分数据可能遗漏周中调整；按最近可见观察使用，不能倒灌下一次观察。
- 修正可能暴露新的数据或账本阻断，这是正确失败，不得继续通过放宽规则绕过。
