# 外部金融数据连接器适配设计

## 定位

外部连接器只作为数据补强和前向验证入口，不直接成为回测数据库，也不直接触发交易。

可接入的候选包括 WorkBuddy/飞书侧可用的金融数据连接器、BaoStock 或其他公开数据源。候选名称不代表当前项目已经安装、授权或验证可用。

## 适配边界

连接器适配器必须完成：

1. 记录供应商、连接器版本、查询时间和查询参数；
2. 保存原始响应到新的 `data/imports/<source>_<timestamp>/` 目录；
3. 生成逐文件大小、SHA256、行数和字段清单；
4. 将供应商字段映射到数据契约，但不覆盖既有快照；
5. 在重叠日期上与现有 canonical 数据做独立比较。

适配器不得完成：

- 直接修改 `data/canonical/`；
- 直接修改策略参数或历史研究结果；
- 把实时接口响应当作历史成交回报；
- 在没有人工确认的情况下接入自动下单。

## 最小验收字段

除基础日线外，若要解除当前 shadow replay 阻塞，至少需要：

- `trade_date`、`code`、`tradestatus`；
- `upper_limit`、`lower_limit`；
- `buyable`、`sellable` 或可审计的等价规则证据；
- 停牌/不可交易原因；
- 来源、版本和时间戳。

## 重叠核验

接入后先选取已有 canonical 数据中的固定证券和日期窗口，逐日核验：

- 日期覆盖是否一致；
- 原始不复权价格是否一致；
- `tradestatus` 是否一致；
- 涨跌停字段的定义和精度是否一致；
- 公司行动日前后是否出现不可解释断点。

只有重叠核验通过，且导入快照状态为 `SEALED`，才允许进入 shadow replay。否则只保留为候选来源审计结果。

## 当前状态

当前 Codex 项目尚未连接 WorkBuddy 或飞书金融连接器；本设计先建立适配边界，避免后续接入时破坏可复现性。
