# 真实股数虚拟账户实施计划

日期：2026-09-09
依据：已批准方案 A 的研究通过后建设公司行动及真实账本路径，以及用户继续推进授权。

## 目标和范围

将已冻结的动量与低波动信号接入真实股数、现金、应收款和每日对账账户。保留研究运行供比较；新增账户从明确初始资金和零持仓开始重放。当前阶段仅虚拟账户。

## 输入盘点

`tools/inventory_share_ledger_inputs.py --run <已封存研究运行>` 验证运行状态、验收报告及清单所有文件的大小与 SHA256，然后生成独立盘点报告。报告记录主策略和 20/40 只敏感性目标的证券数、主策略实际持仓观察区间、已有公司行动文件及待核对项。输出写入 `reports/SHARE_LEDGER_INPUT_INVENTORY_<UTC时间>.json`，各次保留。

盘点中的持仓范围用于排定数据核验优先级。未来真实账户因整数手、资金和公司行动产生不同持仓时，按新的实际暴露补齐证据，不用既有持仓倒推过滤股票池。没有事件文件一律表示覆盖未知。

## 实施顺序

1. 读取既有本地 BaoStock 分红及复权因子适配器，先对主策略当前持仓做小批响应覆盖检查，记录字段、日期、空响应和失败。通过后扩展到历史实际持仓及承继证券。
2. 新增原始快照存于 `data/imports/`，固定查询参数、来源时间、期望文件数和 SHA256；原始响应保持不变。独立核验通过后才生成标准事件。
3. 在 `src/ashare_lab/selection/` 新建真实账户模块。整数买入量依据证券板块和日期规则；现金扣款用未复权成交价。每日可卖数量独立记录，以实现 T+1。
4. 分红在登记日收盘锁定资格、除息日确认应收、到账日计入现金。核对是否存在同日除息到账；按事件身份防止重复。税费依实际适用持有期与资料处理，未知税务规则阻断相应账户晋级。
5. 送转、配股和换股分别处理，明确股数生效日、上市可卖日、资金缴付及零碎股规则。现有换股纯函数只提供数量映射，缺失的现金/碎股安排继续要求证据。
6. 虚拟撮合记录订单、成交、拒绝和撤单。每日用未复权收盘核对现金加应收加市值等于权益；缺失估值或未知公司行动保持阻断。
7. 独立重放账本，并对相同信号、相同日期与研究账户做差异归因：整数手、闲置现金、到账时间、交易成本和税费。通过后冻结前向验证起点和参数，逐日生成可追溯虚拟报告。

## 验收边界

- 研究验收通过只启动本计划，不授予虚拟账户完成状态。
- 每个证券的公司行动覆盖需有证据；单纯前复权连续或事件文件数量不构成完整性证明。
- 需要覆盖当天买入不可卖、部分老持仓可卖、停牌与涨跌停拒单、现金不足、分红到账及重复事件、换股和缺失估值场景。
- 账户采用同一资金再投资口径的基准；含分红再投资指数另列为研究参考。
- 历史已观察区间标记为已接触历史留出；新增日期前向验证需事先冻结，不能回填成事前交易。

## 代价与风险

新账本可能降低既有研究表现；源数据可能缺少完整税务和特殊公司行动安排。先核验小批再扩展能避免无效全量下载，但小批通过不证明历史全量可用。任何研究阶段的参数选择和结果查看都要继续保留，以便识别过拟合风险。
