# 新开仓组合调度 V1

2026-09-29。落实既有研究规则，不变更风险偏好，不启动实盘。

输入为已通过 manual_rules 的当日 BUY_SIGNAL、已核验当日行业、现有持仓市值、现金、当月已成交常规买入次数。信号必须带规则版本和证据ID。持仓估值必须完整；本版本仅支持没有未完成买单的串行批次，有未完成买单时整批暂停，防止重复占用现金和名额。

排序按3年ROE中位数降序、总经营现金流/总归母利润比降序、代码升序；不是旧观察名单的每股代理排序。最多4股、每行业1股、每月最多2笔常规买入。已有持仓不重复开仓；加仓暂不实现，不能冒充新开仓。首笔预算不超过当次净资产10%，总股票市值加预留预算不超过80%，预算含费用且不得超过现金。多笔计划逐笔预留现金、行业、持仓名额和月度名额。

所有未入选者给出原因。计划ID由版本、信号日、证券代码决定；计划不是订单也不是成交。当前批次内不因高排名候选后来拒单而自动递补，待重新核验后另行规划。重试、持久化与实际成交后释放预留由上层负责，不能把无状态函数当作已运行调度服务。

风险退出不经过本买入规划器，不能被月度买入次数限制。周度/首次启动触发由调用层确认；非决策时点全部返回无计划。输入中的行业与决策时点核验必须来源于证据适配，不能手工置真绕过核验。

风险与代价：不递补和暂不加仓可能减少仓位；4笔首仓理论投入约40%，不是80%满仓策略。组合层落地不代表所有财务、公司行动、定时运行已完成。
