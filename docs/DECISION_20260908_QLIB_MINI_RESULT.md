# Qlib 风格最小模型实验结论

日期：2026-09-08

## 实验边界

本实验未安装 Qlib 或 LightGBM，使用纯 NumPy 岭回归作为工程适配基线。输入为标准层中按代码排序的前50只股票；特征只使用信号日及以前的5/20日价格收益、20日波动率和5日成交量/成交额中位数。标签为未来第2个交易日相对未来第1个交易日的前复权收盘收益，和当前核对到的 Qlib Alpha158 默认标签语义一致。训练区间为2018—2022年，验证为2023年，测试为2024-01-01—2026-08-31。该结果不是 Qlib 官方结果复现。

## 结果

结果文件：`reports/QLIB_MINI_EXPERIMENT_20260908.json`

- 训练样本：55,732
- 验证样本：11,348，242个交易日，平均 Rank IC `-0.046943`
- 测试样本：29,078，645个交易日，平均 Rank IC `-0.048380`
- 验证和测试中位数 Rank IC 分别为 `-0.035962`、`-0.069433`

随后以相同公式、标签、时间边界和 `alpha=10` 扩大到100只股票：训练 110,879 条、验证 21,920 条、测试 55,780 条；验证平均 Rank IC `-0.018680`，测试平均 Rank IC `-0.008198`，中位数分别为 `-0.026981`、`-0.003198`（见 `reports/QLIB_MINI_EXPERIMENT_100_20260908.json`）。方向仍为负，不能晋级。

## 决策

当前简化特征、标签和岭回归组合不晋级，不接入组合账本，不进入虚拟盘。负 IC 在时间外测试中方向一致，至少说明“直接把这组价格量特征接上模型”没有形成可接受的候选证据；它不是长期亏损的证明，也不是继续调参的理由。

## 标签语义修正后的复跑

官方源码核对后，标签修正为 `close_qfq(t+2) / close_qfq(t+1) - 1`，与 Alpha158 默认标签语义一致；此前结果文件使用的是旧标签，应视为历史对照，不得与新结果混用。修正后50只股票复跑（`reports/QLIB_MINI_EXPERIMENT_50_V2_20260908.json`）：验证平均 Rank IC `-0.047716`，测试平均 Rank IC `-0.029192`，仍为负，且未出现改善。因此“不晋级”结论保持不变。

修正标签后再扩大到100只股票（`reports/QLIB_MINI_EXPERIMENT_100_V2_20260908.json`）：验证平均 Rank IC `-0.012184`，测试平均 Rank IC `+0.006038`。测试期略为正，但验证期仍为负，且绝对值接近零；不能只因测试期改善而晋级，当前仍记为混合结果、不接入组合账本。

加入已审计的 KBar、滚动、成交量和价格位置字段后，22特征子集在100只股票上重新训练（`reports/QLIB_ALPHA_SUBSET_EXPERIMENT_100_20260908.json`）：训练 110,349 条、验证 21,746 条、测试 55,421 条；验证平均 Rank IC `+0.006058`，测试平均 Rank IC `+0.013963`，中位数分别为 `+0.003053`、`+0.012399`。这是弱正向预测质量信号，不是收益证明；尚未经过滚动训练、成本和组合账本验证，因此暂不晋级。

按年份拆分后，测试 Rank IC 均值为：2024 `+0.007010`、2025 `+0.018650`、2026 `+0.017360`；验证年2023为 `+0.006058`。跨年方向一致但量级很小，仍不能替代组合级验证。

年度滚动训练复核（每个年份只使用此前数据拟合，见 `reports/QLIB_ROLLING_EXPERIMENT_100_20260908.json`）得到：2024 `+0.007068`、2025 `+0.013305`、2026 `+0.011173`。滚动训练下方向仍一致，但信号依然偏弱；这只提高了时间语义可信度，不构成收益或交易晋级证据。

首次接入现有研究账本的组合烟测未完成：模型选出的 `000540` 持仓连续超过60个交易日没有有效前复权价格，触发数据连续性闸门并停止（见 `reports/QLIB_ALPHA_PORTFOLIO_SMOKE_100_20260908_FAILURE.json`）。不使用未来数据过滤候选，也不放宽闸门，因此没有生成可晋级的组合收益结果。

进一步诊断显示 `000540` 的3277行行情中前复权开盘/收盘字段均完整，最后观测日为2023-06-30；阻断来自行情终止（疑似退市或证券沿革），而非价格字段缺失。当前系统没有经核验的退市处置价，因此不能继续冻结持仓或伪造退出（详见 `reports/QLIB_ALPHA_PORTFOLIO_SMOKE_100_20260908_DEL七_诊断.json`）。

2026-09-09 复核确认：上述阻断的上游根因是烟测未按信号日历史沪深 300 成分过滤；`000540` 的成分观察止于 2018-12-10，不应在 2023 年进入候选。按最近可见历史成分修正后，组合账本完整跑通。2023-01-03 至 2026-08-31，模型组合总收益 9.75%、年化 2.68%、最大回撤 -23.29%、零利率夏普 0.24；同区间 510300 含分红总回报为 29.41%、年化 7.60%、最大回撤 -22.58%、夏普 0.50。模型组合在收益、回撤和夏普三项均被基准支配，判定 `REJECTED_BENCHMARK_DOMINATED`，不晋级。

固定前 100 只历史代码经时点成分过滤后，每期实际模型候选仅 18—19 只，低于目标 20 只。这进一步说明该烟测只能做工程连通性验证，不能外推到完整沪深 300。

## 风险与后续

50只股票不是全市场，特征也不是 Alpha158 的完整实现；因此不能把负 IC 外推为所有 Qlib 方法无效。若要继续，必须先固定 Alpha158 字段映射、标签定义和训练边界，再做更小的单元级一致性验证；只有一致性通过，才有理由扩大股票范围。任何扩大实验都应保留当前失败结果作为对照，不能删除或覆盖。
