# 左右侧价格机制诊断实验计划 V1

状态：待批准；未实现、未运行、无收益结果。

## 目的

用尽量少的新数据工作，先回答两个窄问题：

1. “从过去一年高点回撤至少20%”之后，未来1、3、6个月的收益与下行风险是否值得继续研究？
2. “突破过去120日收盘高点且60日趋势改善”之后，同期收益与下行风险是否值得继续研究？

这不是完整选股策略、组合回测、实盘建议或盈利证明。首轮不使用财务筛选、估值PE/PB、行业筛选、加仓、止损、仓位优化或虚拟账户，不因结果改阈值。

## 数据和可用范围

- 输入只读使用已封存 `data/canonical/stock_selection_v1/` 中由同批历史快照转换的前复权日线、`trade_calendar.csv` 和 `membership_weekly.csv`；运行前核对该标准层清单及其引用的原始清单 SHA256，不回读旧项目目录。
- 股票池按实验信号日的历史成分截面限定；每周仅在成员快照明确存在的日期评估信号，不把“历史上曾经是成分股”的940只股票全程当成成员，也不向前填充成员状态。
- 价格来源是历史沪深300成分，不是全A；成分快照按周查询，可能遗漏周中临时调整，且尚未与中证官方公告全量核对。结果仅用于机制初筛，不能声称适用于全A。
- 使用封存前复权价格比值作为研究收益代理；不构造现金/真实股数账户，不声称证明实际可成交。运行前须重验两个快照清单哈希、质量验收结果和所需证券/日期覆盖。

## 预先固定的信号定义

- 信号频率：封存历史成分文件中的每个实际查询日；信号使用该日收盘价，观测入场日为交易日历中的下一交易日。若下一交易日该证券没有有效开盘价，则该信号不构造成交观察，记录为缺失/不可观察。
- L1价格形态：信号日收盘价相对信号日前252个交易日收盘价最高值回撤至少20%。不含当日的历史高点；252个日历交易日窗口内必须逐日有有效收盘价，缺失不压缩窗口。
- R1价格形态：信号日收盘价高于此前120个交易日最高收盘价，且信号日60日均价高于20个交易日前的60日均价；窗口须按共同交易日历完整，缺价不压缩窗口。
- 同一证券、同一形态触发后126个交易日内不重复记信号，避免连续触发膨胀样本数；L1与R1分别去重。定义冲突/缺失时阻断该条信号，不用近似值补齐。
- 首轮不将L1/R1合并成组合，不指定信号优先级或持仓名额；分别报告，避免虚构未完成的基本面排序。

## 观察结果

每条有效信号从日历下一交易日开盘起算至第21、63、126个共同交易日收盘，计算前复权收益；持有期内任何必要日线缺失则该期限标记不可计算，不跨缺失日压缩窗口。同时统计区间最大有利/不利波动、正收益比例、样本数、每年触发数与可计算覆盖率。与同一成分截面同一信号日的全体成员等权未来收益作描述性比较。

必须按信号年份和固定四年阶段列示，不只给总平均；阶段机械划分为2011—2014、2015—2018、2019—2022、2023—2026，不依据收益结果改界。至少报告中位数、均值、10/25/75分位及极端亏损分位。没有充足样本的分组标记样本不足，不做结论。观察终点不足对应持有期的近期信号只报告覆盖，不纳入完整期限收益。

## 研究纪律、风险和准入边界

- 本试验不新增行情或财报抓取，不改已封存快照，不使用当前股票池回填历史。
- 条件阈值来自现有策略草案，是待验证假设，不是GitHub项目已证明有效的规则；即使结果好也不据此择优调参。
- 历史区间和策略设计已被研究者查看，全部结果标为 `HISTORICAL_DIAGNOSTIC_WITH_PRIOR_EXPOSURE`，不得称作独立样本外或未来验证。
- 价格触发后的下一日开盘只是研究观测价格，不处理涨跌停、滑点、交易费用、停牌成交、公司行动份额变化或真实订单拒绝；这些缺口可能夸大可实现性。
- 若机制值得继续，下一阶段再设计含财务/估值门槛、成本和可执行组合规则的完整策略版本；规则冻结后开始真正向前的虚拟验证。机制不支持则记录不支持，不能靠调参制造通过。
- 实施将新增一个独立实验脚本、合成边界测试和不可覆盖的结果报告，不修改旧策略、旧回测、现有数据或虚拟账户。
