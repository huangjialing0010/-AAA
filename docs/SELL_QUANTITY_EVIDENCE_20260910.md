# 卖出数量检查的证据与适用边界

## 主板零股

[上交所关于进一步明确竞价交易申报数量及前端控制有关事项的通知](https://www.sse.com.cn/lawandrules/guide/stock/jyglywznylc/tz/c/c_20230209_5716007.shtml)明确：不足100股部分可单独或随整手一次卖出，不得拆成多个零股订单。299股例子允许100与199、99与200，禁止298与1、198与101。

`ROUND100_WITH_WHOLE_REMAINDER` 据此检查非整手卖出数量必须包含整个总持仓零股余数，可卖股数仍独立约束。不能只用可卖股数冒充总持仓。

## 科创板小额余股

[上交所科创板投资者问答](https://edu.sse.com.cn/tib/qa/)说明：申报至少200股，不足200股余额需一次卖出。`MIN200_OR_ENTIRE_BALANCE` 检查小于200股的申报必须等于总持仓且全部可卖。

## 尚未授权的推断

上述是规则检查函数，不是自动证券分类器。每证券、每日期需由核验后的规则数据源选择策略；默认 UNVERIFIED 继续阻断卖出。当前资料未证明所有历史年份、深交所及其他板块统一适用。不依据股票代码直接放行，不把2026年规则倒灌历史。

还需验证单笔上限、价格最小变动单位、申报方式和有效价格范围。PRECHECK_PASS_NOT_FILL 不代表完整交易所校验或成交。已有回测结果保持不变。
