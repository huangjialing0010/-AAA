# 模拟盘首版账户报告

本实现承接报告复盘V2，不改变策略、账本或旧报告。报告纯读取：首批run.json、执行事件及其manifest，验哈希并检查事件绑定到同一订单来源。不得写回订单和成交。

报告保存在 `reports/manual_paper_<UTC时间戳>/`，含 `report.json`、`daily.md`、`weekly.md`、`monthly.md`、`manifest.json`。所有文件只追加；同一份来源重复构建返回原报告，不叠加收益。周/月未结束明确标为周内/月内，开户前的空白不填零。

首版范围是首笔买入事件账本：独立复算现金、整数持仓、费用；发现重复终态、跨证券成交、现金与成交不一致即报错，不生成正常报告。未实现的卖出、多批次、分红或外部资金流不伪装支持。

当天有持仓但无当天有效估值，总资产和累计收益显示不可计算；不将旧价当新价。没有成交且账本截至当天完整时，全现金账户可以报告净损益0元，但明确“没有交易样本，不能评价策略收益能力”。缺逐日净值序列时，不报告回撤、胜率和超额收益。

日报分别列信号、订单、成交、订单拒绝、准入排除、撤单；同一订单多次检查不累计为多笔订单。周/月首版汇总当前账户实际覆盖区间；不是完整历史绩效模块，也不能代替持续持仓循环。日报事实、判断、后续事项分开。

累计记录与本期记录分别计数。本期信号、订单、准入排除按本批实际生成日归属；成交按成交日，订单拒绝按拒绝检查时刻归属。跨日、跨月不把既有成交重复称为本期操作。持仓和累计损益仍属账户状态，不因报告周期切换归零。

自动复盘只输出数据/执行缺口与观察事项，不自动修改策略或创建新订单。收益、回撤、基准、左右侧比较在有效样本不足时保持不可评价。风险：少持仓集中风险；记录完整不等于盈利或实盘可复制。
