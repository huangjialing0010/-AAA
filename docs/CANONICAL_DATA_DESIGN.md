# 标准数据层设计（V1）

## 目的

把一次性导入快照转换为字段统一、时间语义明确、可重复验证的数据层。标准层只解决“数据能否被可信地读取”，不包含选股、交易信号、收益承诺或实盘接口。

## 输入与输出边界

- 唯一输入：`data/imports/legacy_snapshot_20260901/`。
- 唯一输出：`data/canonical/` 和 `reports/canonical_data_quality.json`。
- 转换工具不得读取 `D:\大A`，不得修改导入快照。
- 每次生成都记录输入清单 SHA256、转换版本、输出文件 SHA256 和质量检查结果。

## 目录约定

```text
data/canonical/
├── daily_prices/          # 300只股票的前复权日线，按股票分文件
├── financial_reports/     # 574只股票的财务报告，按股票分文件
├── industry_index/        # 31个申万一级行业指数，按指数分文件
├── reference/             # 日历、基准、当前股票池、当前行业映射
└── manifest.json          # 标准层生成清单
```

## 时间语义

### 日线

- `trade_date` 是交易日期。
- 股票价格来自明确标记为 `qfq` 的文件，`adjustment=qfq`。
- V1 不推导涨跌停、停牌或除权事件；后续回测不得据此假设一定可成交。

### 财务报告

原始数据没有公告日期。V1 生成 `available_date_assumed`，只作为保守研究代理：

- 一季报（03-31）：当年 05-15；
- 半年报（06-30）：当年 08-31；
- 三季报（09-30）：当年 11-15；
- 年报（12-31）：次年 04-30；
- 非标准报告期：报告期后 120 天，并标记为回退规则。

正式回测在日期 `t` 只能使用 `available_date_assumed <= t` 的记录。这个字段不是实际公告日，可能让数据晚于真实可用时间，代价是信号滞后；但它仍不能替代正式公告日数据。

## 缺失值和单位

- 原始 `False`、空字符串和无法解析的值统一输出为空，不得转成 0。
- `万` 和 `亿` 分别转成基础货币单位的 `10000` 和 `100000000` 倍。
- 百分数字段从百分数转成小数，例如 `29.86%` 输出为 `0.2986`。
- 不对缺失值插值，不静默删除异常记录。

## 当前截面数据限制

`current_universe.csv` 和 `current_industry.csv` 都写入 `historical_use_allowed=false`。它们只能描述导入时的当前截面，禁止回填到历史日期，否则会产生幸存者偏差和行业穿越。

## 质量闸门

生成过程遇到以下问题直接失败：

- 输入清单或必需目录缺失；
- 股票日线代码或日期重复；
- OHLC 缺失、非正数或高低价关系不可能；
- 当前300只股票缺少日线或行业映射；
- 输出数量、哈希或清单不一致；
- 当前截面文件被误标为可用于历史。

基准的零成交量是已知源数据问题，V1 保留原值并在质量报告中计数，不把它伪装成正常成交量。
