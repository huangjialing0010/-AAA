这是一个独立的新项目，目标是用可追溯数据验证 A 股策略，并在同一规则下运行虚拟交易。

当前范围：

- 建立基础数据、数据质量和时间语义契约；
- 建立无未来数据的回测内核；

- 暂不设计或接入任何实盘接口。

旧项目只作为一次性原始数据来源。导入完成后，本项目不得在运行时读取旧项目目录。
